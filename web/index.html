Keysmith in MetaMask

One wallet signature starts a key hierarchy. Keys exist only in this tab: reload, and step 5 rebuilds them from the wallet and the chain. Every MetaMask prompt is announced in the log, in orange, before it appears.

  1. Connect

    Ask MetaMask for an account, and add or switch to the devnet.

  2. Start a keyspace

    Mint a random keyspace and sign KeyspaceKey. The signature becomes the root key and is never shown or stored.

    What MetaMask is asked to sign 
    Start a keyspace to see it.

  3. Create a dataset

    Encrypt in the tab, upload ciphertext to the SP, and create a dataset carrying only the keyspace and its commitment.

  4. Delegate to an agent

    Authorise a session key on chain, hand it the agent-memory scope key, and let it write with no further prompts.

  5. Recover from the wallet

    Forget the keys, or reload the page, then rebuild every key from the chain with one signature per keyspace.
